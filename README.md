# RetroTapes
RetroTapes is a VHS rental service where you can:

- List, search, and filter movies to rent
- View active movie rentals
- View historical movie rentals

It is built and maintained by a team of .NET development students from YH Akademin in Sweden.

## Installation
```bash
git clone https://github.com/VincentBrodin/RetroTapes.git
cd RetroTapes
dotnet restore
```
